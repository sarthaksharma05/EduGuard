# EduGuard AI — Landing (Vite + React + Tailwind)

Quick scaffold to run the `Home.jsx` landing page locally.

Install dependencies and run dev server:

```bash
npm install
npm run dev
```

Open the URL printed by Vite (usually http://localhost:5173).

Notes:
- This is a minimal Vite React setup with Tailwind CSS configured.
- `src/Home.jsx` contains the full landing page component.
